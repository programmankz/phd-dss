Как подключить реальные данные

python -m dss.cli fetch gdp        # IMF WEO (при отказе — World Bank WDI) → data/gdp_growth.csv
python -m dss.cli fetch fx         # НБ РК, дневные курсы → data/fx_rates.csv (долго, с докачкой)
python -m dss.cli fetch nse        # Yahoo Finance, 20 акций NSE → data/prices_nse.csv
python -m dss.cli warmup           # предварительный расчёт всех модулей
ФайлФорматМодуль
gdp_growth.csvcountry, 1980, …, 2024 — рост реального ВВП, %I
fx_rates.csvDate, USD, EUR, CNY, RUB — тенге за единицуII
prices_kase.csvDate, HSBK, KSPI, … — цены закрытия (экспорт с kase.kz)III, IV
fundamentals_kase.csvticker, sector, PB, PEIII
prices_nse.csvDate, HDFCBANK.NS, … — цены закрытияIII, IV

Требования к файлам: даты в формате ГГГГ-ММ-ДД (или ДД.ММ.ГГГГ), дробная часть через точку, цены и курсы положительные; в ценах — не меньше 6 бумаг и 300 торговых дней, в курсах — не меньше 5 лет истории, в панели ВВП — строка Kazakhstan и годы по обе стороны 2014 г. Файл с ошибкой не останавливает расчёт: для этого набора временно используются демо-данные.

После замены файлов нажмите «Сбросить кэш и пересчитать».
