# Инвестиционная привлекательность Казахстана: индекс KASE и рост ВВП

Файл создан скриптом `scripts/attractiveness.py`. Расчёт разведочный: гипотезы заранее не регистрировались, параметры по выборке не подбирались.

**Показатель.** A = 1, если выполнено условие на рост реального ВВП, иначе 0. Определение выбирает пользователь: `sign` (рост положителен), `accel` (рост ускоряется, ΔY > 0), `panel` (рост положителен, классификаторы обучаются на панели стран [A1]).

**Опережающий индикатор.** Доходность индекса KASE за 6 мес. до начала периода. Окно задано заранее.

**Модели.** ARIMA (основная): порядок интегрирования d по тесту Дики–Фуллера на уровне 5%, p и q по AIC, при d = 1 без дрейфа. ARIMA + KASE: та же модель того же порядка на той же выборке с доходностью индекса как внешним фактором. Для сравнения оставлена ARIMA по сетке порядков [A1] на всей истории роста, где d = 1 всегда. AR(1), AR(1) + KASE, логистическая регрессия, случайный лес, градиентный бустинг. Проверка вне выборки расширяющимся окном. Признаки машинного обучения: рост в предыдущем периоде, средний темп и стандартное отклонение роста за 3 года (4 квартала), доходность KASE.

**Данные.** Годовой рост ВВП: `data/gdp_growth.csv`. Квартальный рост г/г: `data/gdp_quarterly_kz.csv` (Бюро национальной статистики, с 2011 года). Индекс KASE с 12.07.2000: `data/index_kase_2000_2007.csv` и `data/index_kase.csv`.

## Выводы

1. **На годовых данных индекс KASE улучшает прогноз роста, но значимость зависит от формы модели.** В ARIMA, порядок которой выбран по формальной процедуре (d = 1 по тесту Дики–Фуллера), добавление индекса снижает RMSE с 3,66 до 3,33 п.п. (на 9%), тест Диболда–Мариано p = 0,077: на уровне 5% прирост не подтверждён. В стационарной форме ARIMA(1,0,0), то есть AR(1), индекс значим в уравнении роста (b = 0,05; p < 0,001 при ошибках Ньюи–Уэста) и снижает RMSE с 2,94 до 2,52 п.п. (на 14%), p = 0,033. Выборка мала: 23 года, 13 прогнозов.
2. **На квартальных данных связь не подтверждается.** Коэффициент при индексе незначим (p = 0,40); ARIMA + KASE точнее ARIMA на 1% (3,26 против 3,30 п.п., p = 0,30), AR(1) + KASE не точнее AR(1). Квартальный ряд есть только с 2011 года и сильно колеблется от квартала к кварталу.
3. **Определение «рост положителен» почти не оставляет нулей.** В проверке один отрицательный год из 13 и два отрицательных квартала из 34. Ни одна модель не превосходит постоянный прогноз, и сравнивать модели на таком показателе нельзя.
4. **Определение «рост ускоряется» сбалансировано, но предсказывается слабо.** Лучшая точность на годовых данных 0,62 (AR(1) + KASE) на 13 прогнозах, на квартальных 0,65 (случайный лес) на 34. Модели машинного обучения не лучше линейных.
5. **Гетероскедастичность остатков не обнаружена** (ARCH-LM и Бройш–Паган, p > 0,1), при этом разброс роста по периодам различается. Значимость везде оценена по устойчивым ошибкам.
6. **Выбор порядка интегрирования решает больше, чем индекс.** На годовых данных тест Дики–Фуллера на 10–22 наблюдениях не отвергает единичный корень, выбирается d = 1, и ARIMA (RMSE 3,66) проигрывает стационарной AR(1) (2,94). На квартальных данных, начиная с окон длиннее 38 кварталов, тест выбирает d = 0, то есть рост стационарен. ARIMA по сетке [A1] на всей истории роста с 1991 года хуже в обоих случаях (4,41 и 3,50).
7. **Кластеры стран.** По среднему темпу и разбросу роста за 2000–2024 гг. наибольший силуэт у двух кластеров (0,44 против 0,37 у трёх–шести): 150 экономик с низким ростом и низким разбросом и 51 с высоким ростом и высоким разбросом. Казахстан во втором. Разбиение зависит от периода: если включить 1990-е, два кластера отделяют только девять стран с экстремальным разбросом.
8. **Ограничения.** Расчёт разведочный. Ряды ВВП взяты в текущей редакции, без учёта пересмотров. Шок 2020 года индекс не предвидел. Окно 6 месяцев задано заранее по смыслу (полугодие) и совпадает с лучшим из окон, опробованных в предварительном просмотре данных, поэтому значимость годового результата может быть завышена.
