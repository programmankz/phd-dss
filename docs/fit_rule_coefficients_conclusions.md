## Выводы

1. Данные 2008–2019 гг. коэффициенты не определяют. Коэффициент Шарпа на сетке меняется в пределах 0,03: для доли акций 12 значений из 16, для доли доллара 202 сочетания из 221 лежат в пределах 0,02 от лучшего. Вероятность неблагоприятного режима в этом периоде была высокой только в 2010–2011 гг., поэтому чувствительность доли акций оценивается по одному эпизоду.
2. Подобранные значения стоят на краях сетки (чувствительность 0; наклон 1,2) и от назначенных отличаются. Разность Шарпа между подобранными и назначенными значениями на периоде подбора статистически незначима (p = 0,59 и 0,69), то есть назначенные значения входят в множество неотличимых от лучшего.
3. На 2020–2026 гг. подобранные значения результата не улучшают. Правило для доли акций с чувствительностью 0 даёт просадку −13,5% против −10,6% (разность значима, p = 0,009). Правило для доли доллара с подобранными значениями держит в долларе 79% защитной части против 51% и снижает Шарп на 0,17 (p = 0,017); доходность в окне 2020 г. выше на 1,3 п.п.
4. Подбор по истории ответа на вопрос о происхождении коэффициентов не даёт: оптимум плоский и неустойчивый. Назначенные значения остаются экспертным допущением; их обоснованием служат анализ чувствительности (±25%) и то, что подбор по независимому периоду не даёт лучшего правила.
5. Расчёт разведочный, выполнен после основных экспериментов и по одному критерию (Шарп). Значения по умолчанию не менялись.
