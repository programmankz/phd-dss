# Базовые стратегии в общем бэктесте KASE

Результаты `python scripts/baselines.py`; таблица `docs/results/baselines_kase.csv`. Каждая базовая стратегия заменяет только веса рисковой части: издержки, учёт, защитная часть, даты ребалансировки и окно ковариации (252 дня, Ledoit–Wolf) — те же, что в таблице 4. Профиль moderate, издержки 10 б.п., лимит на актив профиля применяется ко всем правилам. «+ KZT» — d = d0, h = 0; «правила I–II» — d и h по правилам интеграции, как в полной СППР. Константы Блэка–Литтермана (δ = 2,5, τ = 0,05, IC = 0,05) взяты из учебных значений и не подбирались; взгляды — по рангам Модуля IV (правило Гринолда α = IC·σ·z).

DSR — дефлированный коэффициент Шарпа (Bailey, López de Prado, 2014): вероятность, что истинный Шарп выше максимума, ожидаемого среди N неэффективных стратегий; N = число конфигураций прогона + 16 конфигураций абляции. SR0 — этот порог (годовой).
