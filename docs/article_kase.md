# Эксперимент статьи [A4] на KASE

Файл создан скриптом `scripts/article_kase.py`. Метод статьи «Machine Learning-Based Portfolio Optimization Using Cross-Sectional Signals: Evidence from the NSE Market» повторён без изменений, заменён только файл цен. Параметры по выборке не подбирались.

**Протокол статьи.** Признаки: лог-доходность, RSI(14), MACD и сигнальная линия, ATR(14), ширина полос Боллинджера, отношение к SMA(14), объём. Модели: Linear, Ridge, Lasso, SVR, Decision Tree, Random Forest, Gradient Boosting (четыре нейросетевые модели статьи требуют TensorFlow и здесь не считались). Одно хронологическое разбиение 80/20, сглаживание по 10 прогнозам, ранги s = Rank(r̂)/N. Четыре стратегии, ежедневная ребалансировка, выборочная ковариация за 252 дня, без издержек, 0 ≤ w ≤ 1. Шарп при ставке 5%, как в статье; для KASE дополнительно при средней базовой ставке НБ РК за тестовый период.

**Наборы KASE.** 9 бумаг файла `data/prices_kase.csv` имеют общую историю только с 12.2022 (листинг KMGZ), поэтому тест короткий. Набор из 7 бумаг без KSPI и KMGZ даёт историю с 12.2018 и вдвое более длинный тест. Цены с дивидендами.

## Выводы

1. Метод статьи [A4] переносится на KASE без изменений: тот же код считает оба рынка, меняется только файл цен.
2. На KASE в тестовой выборке все четыре стратегии дали высокую доходность: 19,5–46,2% годовых на наборе из 7 бумаг и 17,6–35,5% на наборе из 9 бумаг. Это период роста рынка: портфель равных весов без всякого прогноза дал 36,5% и 17,6% годовых.
3. Преимущество стратегий на сигналах над равными весами статистически не подтверждено. На 7 бумагах разница Шарпа у Max Signal-to-Risk +0,28 (p = 0,78), у Signal Weighted +0,23 (p = 0,53). На 9 бумагах разница у Max Signal-to-Risk +2,11, но тест короткий (182 дня) и p = 0,07, с поправкой Холма 0,28.
4. Ранговая корреляция прогнозов с фактической доходностью на KASE положительна: на 7 бумагах IC от 0,02 до 0,07, у SVR, Random Forest и Gradient Boosting t(IC) больше 2. На выборке NSE статьи IC отрицательный или около нуля. По квадратичной ошибке ни одна модель не точнее прогноза «доходность равна нулю» ни на одном рынке.
5. Шарп при ставке 5%, как в статье, для KASE завышает результат: тенговый депозит давал около 16,5%. При этой ставке Шарп равных весов на 7 бумагах 2,03, на 9 бумагах 0,16.
6. Опубликованная строка таблицы IV статьи (21,61% / 17,40% / 0,95) на данных NSE этим кодом не воспроизводится (см. `docs/reproduction.md`); сравнение KASE со статьёй поэтому ведётся и с опубликованным значением, и с расчётом на NSE.
7. Ограничения: одно разбиение 80/20 даёт один тестовый отрезок, без издержек и без лимитов на бумагу, как в статье; четыре нейросетевые модели не считались; 7–9 бумаг против 20 на NSE.
