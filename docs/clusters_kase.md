# Модуль III на данных KASE: меры сходства, ликвидность, устойчивость

Результаты `python scripts/clusters_kase.py`; таблицы `docs/results/clusters_kase_compare.csv` и `clusters_kase_table.csv`. Окно — 252 торговых дня до 09.10.2026 (03.10.2025 – 09.10.2026), 7 бумаг таблицы 4, K-medoids (PAM), k по силуэту. Признаки ликвидности: доля дней без изменения цены (Lesmond и др., 1999) и логарифм меры Амихуда по дневному обороту в тенге. Устойчивость — скорректированный индекс Рэнда (ARI) между разбиением исходного окна и разбиениями 200 циркулярных блочных бутстреп-выборок дней (блок 10 дн., то же k). Бэктест — полная СППР таблицы 4 (2023–2026) с этим вариантом Модуля III, остальное без изменений.

Кластеры-одиночки дают варианты: features, features + liquidity, correlation, correlation + liquidity, blend. Наиболее устойчив вариант «features + liquidity» (ARI 0,50). Разброс Шарпа СППР между вариантами 1,17 – 1,46 меньше ширины бутстреп-интервалов Шарпа таблицы 4 (около ±1,3), поэтому выбор меры сходства по итоговой доходности не обоснован; выбирать её нужно по устойчивости и интерпретируемости, до теста.
