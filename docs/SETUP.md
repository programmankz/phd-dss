## 1. Установить Python

Нужен Python **3.10 или новее**. Рекомендуется **3.12** — именно на нём CI проверяет точные версии пакетов из `requirements-lock.txt`. Версии 3.13–3.15 тоже работают с lock-файлом.

> **macOS:** встроенный `/usr/bin/python3` — это Python 3.9 от Apple. Он **не подходит**: проект требует ≥ 3.10, а версия 3.9 больше не получает обновлений безопасности.

Проверить версию: `python3 --version`.

**macOS** (через [Homebrew](https://brew.sh)):

```bash
brew install python@3.12
python3.12 --version          # должно вывести Python 3.12.x
```

**Windows:** скачайте установщик 3.12 с [python.org](https://www.python.org/downloads/) и при установке отметьте **«Add python.exe to PATH»**. Проверка в PowerShell: `py -3.12 --version`.

**Linux (Ubuntu/Debian):** `sudo apt install python3.12 python3.12-venv`.

## 2. Скачать проект и установить зависимости

Пакеты ставятся в **виртуальное окружение** `.venv` внутри папки проекта — так они не смешиваются с системными.

**macOS / Linux:**

```bash
git clone https://github.com/programmankz/phd-dss.git
cd phd-dss
python3.12 -m venv .venv                         # создать окружение (один раз)
source .venv/bin/activate                        # включить окружение
python -m pip install -r requirements-lock.txt   # установить пакеты (один раз)
```

**Windows (PowerShell):**

```powershell
git clone https://github.com/programmankz/phd-dss.git
cd phd-dss
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1      # если запрещён запуск скриптов: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
python -m pip install -r requirements-lock.txt
```

На Python 3.10–3.11 вместо `requirements-lock.txt` используйте `requirements.txt`.

### ⚠️ Окружение нужно включать в каждом новом терминале

После `source .venv/bin/activate` (Windows: `.venv\Scripts\Activate.ps1`) строка терминала начинается с `(.venv)`. Без этого команды выполняет системный Python, у которого нет нужных пакетов, — см. [частые ошибки](#5-частые-ошибки).

При включённом окружении пишите `python`, а не `python3`: так точно используется Python из `.venv`.

Проверить, что всё установлено правильно (≈ 1 мин):

```bash
python -m pip install pytest
python -m pytest -q             # ожидается: «… passed»
```

## 3. Запустить

```bash
cd phd-dss
source .venv/bin/activate       # Windows: .venv\Scripts\Activate.ps1
python -m dss.cli warmup        # первый расчёт всех модулей (~1 мин), результаты кэшируются
python -m dss.cli serve         # веб-интерфейс
```

Откройте в браузере **http://127.0.0.1:8050**. Остановить сервер — `Ctrl+C` в терминале. Если порт занят: `PORT=8060 python -m dss.cli serve`.

Без загруженных данных система работает в **демо-режиме**: на каждой странице видна жёлтая плашка. Демо-данные — это **синтетика** (генератор `dss/data/demo.py`): ряды похожи на реальные по форме (девальвации тенге, сырьевой цикл, отраслевая структура KASE), но это не наблюдения, и результаты на них **нельзя** приводить как эмпирические выводы.

Другие команды — в [README](../README.md#быстрый-старт).

## 4. Перейти с демо-данных на реальные

Система ищет CSV-файлы в папке `data/` (другую папку можно задать переменной `DSS_DATA_DIR`). Каждый набор данных подключается **независимо**: если файла нет или в нём ошибка, для этого набора берутся демо-данные, а причина показывается на экране. Жёлтая плашка исчезает, когда реальными стали все наборы.

Источники текущего расчёта выводит `python -m dss.cli warmup` (строки «Источники:») и страница «Данные» в интерфейсе.

| Файл | Модуль | Как получить | Время |
|---|---|---|---|
| `gdp_growth.csv` | I. Макропрогноз | `python -m dss.cli fetch gdp` | ~10 с |
| `fx_rates.csv` | II. Валютные риски | `python -m dss.cli fetch fx` | десятки минут (первый раз) |
| `prices_kase.csv` | III, IV | `python -m dss.cli fetch kase` | ~10 с |
| `fundamentals_kase.csv` | III | создаётся `fetch kase` (только секторы); P/B, P/E — вручную | — |
| `prices_nse.csv` | III, IV (рынок NSE) | `python -m dss.cli fetch nse` | ~1 мин |

### 4.1. Рост ВВП — `gdp_growth.csv`

```bash
python -m dss.cli fetch gdp
```

Сначала команда обращается к IMF World Economic Outlook (индикатор `NGDP_RPCH`, источник статьи [A1]). Сервер IMF сейчас блокирует автоматические запросы (HTTP 403), поэтому команда автоматически переключается на **World Bank WDI** (индикатор `NY.GDP.MKTP.KD.ZG` — тот же показатель: годовой рост реального ВВП, %) и сообщает об этом:

```
  IMF DataMapper недоступен (HTTP Error 403: Forbidden); загружаю из World Bank WDI
gdp_growth.csv (World Bank WDI (NY.GDP.MKTP.KD.ZG)): 214 стран, 1980–2024
```

Значения IMF и Всемирного банка для одной страны могут немного расходиться (разные ревизии национальной статистики) — для воспроизведения цифр статьи [A1] используйте исходный файл статьи `world_gdp_data.csv`, переименовав его в `gdp_growth.csv`.

Формат: `country,1980,1981,…,2024`; обязательна строка `Kazakhstan` и годы по обе стороны 2014 г. (обучение ≤ 2014, тест 2015–2024).

### 4.2. Курсы тенге — `fx_rates.csv`

```bash
python -m dss.cli fetch fx                       # с 2000-01-01 до сегодня
python -m dss.cli fetch fx --start 2015-01-01    # с другой даты
```

Официальные курсы Национального банка РК (USD, EUR, CNY, RUB) загружаются **по одному дню**, поэтому полная история с 2000 г. занимает десятки минут. Загрузку можно прервать (`Ctrl+C`) и запустить снова — она продолжится с последней сохранённой даты. Повторный запуск позже докачивает только новые дни.

Нужно не меньше 5 лет истории.

### 4.3. Цены акций KASE — `prices_kase.csv`

```bash
python -m dss.cli fetch kase                                 # 9 бумаг по умолчанию, с 2019-01-01
python -m dss.cli fetch kase --tickers HSBK,KSPI,KZAP,KCEL,KEGC,KZTO   # свой список
```

Официального API у KASE нет. Команда берёт дневные цены закрытия (тенге) из того же источника, что и графики на страницах акций kase.kz (`/tv-charts/securities`). Источник неофициальный: если kase.kz изменит сайт, команда может перестать работать — тогда соберите файл вручную (см. ниже).

Набор по умолчанию — ликвидные акции с историей не меньше 3 лет:

| Тикер | Компания | Сектор | Торгуется на KASE с |
|---|---|---|---|
| HSBK | Halyk Bank | Финансы | до 2019 |
| KSPI | Kaspi.kz | Финансы | 2021-07 (в этом источнике) |
| CCBN | Bank CenterCredit | Финансы | до 2019 |
| KZTK | Казахтелеком | Телеком | до 2019 |
| KCEL | Kcell | Телеком | до 2019 |
| KEGC | KEGOC | Энергетика | до 2019 |
| KZTO | КазТрансОйл | Энергетика | до 2019 |
| KMGZ | КазМунайГаз | Нефть и газ | 2022-12 |
| KZAP | Казатомпром | Уран | до 2019 |

Не вошли: **AIRA** (Air Astana — на бирже с 2024 г., меньше 3 лет), **BAST** (Баян Сулу — торгуется редко, дневные скачки ±50–150% искажают модели). Добавить их можно через `--tickers`.

Расчёт использует только дни, когда есть цены **всех** бумаг, поэтому общая история начинается с самого позднего листинга — с KMGZ это декабрь 2022 г. (≈ 950 торговых дней). Без KMGZ история начинается с июля 2021 г.

**Ограничения данных:**

* Цены **не скорректированы на дивиденды** — как в торговой системе KASE. У казахстанских эмитентов дивиденды крупные (KEGC, KZTO, HSBK, KZAP), поэтому в дни отсечки цена падает, а доходность занижается.
* **KZTK**: 22–23.05.2025 цена упала на 41% (58 400 → 34 279 ₸) и на этом уровне осталась. Похоже на корпоративное событие (выплата/отсечка после продажи Kcell), а не на рыночное падение. Перед выводами по KZTK проверьте событие на kase.kz; при необходимости уберите бумагу (`--tickers`) или скорректируйте цены до этой даты.

**Ручной вариант** (если `fetch kase` не работает): выгрузите архив торгов каждой акции с [kase.kz](https://kase.kz), сведите в таблицу (первый столбец `Date`, далее по столбцу на тикер) и сохраните как **CSV (UTF-8, разделитель — запятая)** с именем `prices_kase.csv` в папку `data/`:

```csv
Date,HSBK,KSPI,KZTO,KCEL,KEGC,KZAP
2023-01-03,151.2,33100,1480.5,1890,1505,15200
```

(числа условные). Требования: даты — `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`; дробная часть — через **точку**; цены положительные; не меньше **6 бумаг** и **300 торговых дней** с ценами по всем бумагам.

### 4.4. Фундаментальные показатели KASE — `fundamentals_kase.csv`

Если файла нет, `fetch kase` создаёт его с секторами, но **без P/B и P/E** — у kase.kz нет для них машинного источника:

```csv
ticker,sector,PB,PE
HSBK,Финансы,,
KSPI,Финансы,,
```

С пустыми P/B и P/E Модуль III кластеризует бумаги только по ценовому поведению (доходность, волатильность, Шарп, просадка, бета, моментум). Чтобы добавить оценочные признаки, впишите P/B и P/E из отчётности эмитентов или со страниц эмитентов на kase.kz; заполнить нужно **все** строки — столбец, где пропущена хотя бы одна бумага, не используется. Повторный `fetch kase` этот файл не перезаписывает.

### 4.5. Цены NSE (Индия) — `prices_nse.csv`

20 акций из таблицы II статьи [A4], загрузка с Yahoo Finance:

```bash
python -m pip install yfinance
python -m dss.cli fetch nse                      # с 2020-01-01
```

Tata Motors после разделения в октябре 2025 г. торгуется под тикером `TMPV.NS` (вместо `TATAMOTORS.NS` из статьи). Yahoo не корректирует цены на выделение TMCV, поэтому команда сама пересчитывает цены до 14.10.2025 — иначе в ряду был бы ложный обвал на 40%.

Чтобы использовать этот рынок: в интерфейсе выберите набор NSE или в консоли добавьте `--universe nse`.

### 4.6. Пересчитать с новыми данными

После добавления или замены файлов результаты в кэше устаревают. Сбросьте кэш одним из способов:

* в интерфейсе: страница **«Данные» → «Сбросить кэш и пересчитать»**;
* в терминале: удалите папку `.dss_cache` и снова выполните `python -m dss.cli warmup`.

## 5. Частые ошибки

| Что видно | Причина | Что сделать |
|---|---|---|
| В тексте ошибки путь `.../Python3.framework/Versions/3.9/...` или `ModuleNotFoundError: No module named 'pandas'` | Окружение не включено, команду выполняет системный Python | `source .venv/bin/activate` и `python` вместо `python3` |
| `fetch gdp`: `HTTP Error 403: Forbidden` без перехода на World Bank | Старая версия кода | `git pull` |
| `fetch gdp` / `fetch fx`: `URLError` или таймаут | Нет интернета, VPN или прокси блокирует запрос | Проверьте соединение и повторите; `fetch fx` продолжит с места остановки |
| `pip install` долго компилирует numpy/scipy и падает | Python слишком новый — для него ещё нет готовых пакетов | Создайте окружение на Python 3.12 |
| `Address already in use` при `serve` | Порт 8050 занят: сервер уже запущен в другом окне или приостановлен через `Ctrl+Z` (`zsh: suspended`) | В том же окне `kill %1`, иначе `lsof -ti :8050 \| xargs kill`; либо `PORT=8060 python -m dss.cli serve`. Останавливать сервер — `Ctrl+C`, не `Ctrl+Z` |
| Жёлтая плашка не исчезает после загрузки данных | Устаревший кэш или часть наборов ещё демо | Сбросьте кэш (п. 4.6) и проверьте страницу «Данные» |
| «Файл …: …» на страницах интерфейса | CSV не прошёл проверку | Сообщение называет файл, причину и действие — исправьте файл и сбросьте кэш |
