# Выведенные правила интеграции d*, h* против экспертных правил (5)–(6)

Результаты `python scripts/derived_rules.py`; таблицы `docs/results/derived_rules.csv` и `derived_rules_gamma.csv`. Экспертные правила статьи остаются вариантом по умолчанию (`rules="expert"`).

## Правила

Из функции полезности E[R] − γ/2·Var[R] всего портфеля в тенге, R = d·R_E + (1 − d)[(1 − h)·r_KZT + h·(r_USD + δ)], условия первого порядка дают

* d* = clip((μ(π) − r_KZT) / (γ·σ²(π)), d_min, d_max) при h = 0;
* h* = clip((m/γ − d·Cov(R_E, δ)) / ((1 − d)·σ²_δ), 0, h_max), m = r_USD + E[δ] − r_KZT.

μ(π), σ²(π) — моменты смеси двух режимов с весом π = P(рецессии) из Модуля I: μ(π) = (1 − π)μ_N + πμ_R, σ²(π) = (1 − π)σ²_N + πσ²_R + π(1 − π)(μ_N − μ_R)². Рисковая часть для оценки моментов — равновзвешенный рынок всех акций `prices_kase.csv` (история с 2008 г., с дивидендами); неблагоприятный режим — календарные годы, в которых опубликованный рост ВВП Казахстана ниже нижнего квартиля 2000…Y (в данных с 2008 г. отрицательный рост был только в 2020 г., поэтому режим «рост < 0» оценить нельзя). Все моменты — только по дням до даты решения. E[δ] — ожидаемое ослабление тенге Модуля II; σ²_δ и Cov(R_E, δ) — по последним 756 торговым дням. Фаза цикла не используется. γ калибруется для каждого профиля на обучающей части (недельные даты с 01.04.2016 — первый винтаж Модуля I с тестовым годом — до начала теста) так, чтобы среднее d* равнялось d0, и затем фиксируется.

Если ожидаемая избыточная доходность μ(π) − r_KZT отрицательна, d* = d_min при любом γ > 0; если положительна — d* убывает по γ от d_max. Поэтому среднее d* не может превысить долю дат с положительной премией × d_max + остальное × d_min. Когда цель d0 выше этой границы, калибровка упирается в нижнюю границу γ = 0,05 («нет» в последнем столбце), и правило работает как переключатель по знаку оценки премии.

## Оценка

Выведенные правила заменяют восемь экспертных коэффициентов одним параметром γ на профиль, но на данных KASE их поведение определяется знаком и шумом исторических оценок премии: при калибровке, не достигающей d0, правило держит d* у верхней или нижней границы. Более высокий Шарп выведенных правил в тесте 2023–2026 (если он есть в таблице) объясняется тем, что правило держало почти всю рисковую долю в растущем рынке, а не умением предсказывать; проверять его нужно на периодах с падением рынка и с поправкой на множественные сравнения (раздел 9). Для диссертации это аргумент в пользу явной постановки (utility-based) с осторожностью к оценкам μ: усадка оценок премии к априорному значению — следующий шаг, но её параметр должен быть зафиксирован до теста.
