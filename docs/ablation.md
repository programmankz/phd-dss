# Вклад модулей СППР: полный факторный эксперимент и значения Шепли

Результаты `python scripts/ablation.py`; таблицы `docs/results/abl_configs.csv` и `abl_shapley.csv`. Профиль moderate, издержки 10 б.п., та же point-in-time схема, что и в таблице 4 (`scripts/end_to_end.py`).

## Схема

Каждый модуль — «игрок»: I — макроправило доли рисковой части d (иначе d = d0), II — валютное правило доли доллара h (иначе h = 0), III — кластерные лимиты (вместе с IV — лимиты оптимизатора, без IV — равные веса по кластерам с теми же лимитами), IV — веса рисковой части по сигналам (иначе равные). v(∅) — портфель «EW + KZT». Значение Шепли модуля i — средний предельный вклад по всем порядкам включения модулей; сумма значений равна v(все) − v(∅). Интервалы — перцентильные 95% по циркулярному блочному бутстрепу дневных доходностей (одни и те же индексы для всех конфигураций). Для доходности в окне стресса интервал не строится: перестановка дней разрушает окно.
